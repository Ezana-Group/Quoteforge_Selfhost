# Contributing

Thanks for helping improve QuoteForge Pro.

1. Fork the repo and create a branch.
2. `npm ci` then `npm test` (needs Node 18+). All test files must pass.
3. Keep changes focused. Add or update a test in `test/` for anything that changes pricing, documents or the server.
4. Open a pull request describing what changed and why.

## Licensing of contributions

QuoteForge Pro is released under the AGPL-3.0 and is also offered under a commercial license. To keep that possible, every contributor must agree to a Contributor License Agreement (CLA) that lets Ovid International Ltd distribute the contribution under both. Pull requests can't be merged until the CLA is signed. (The CLA text still needs to be drafted by a lawyer; until it exists, please don't accept outside contributions.)
