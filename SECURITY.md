# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email the maintainer via the contact on the repository profile page with a description and steps to reproduce. You will get an acknowledgement within 3 working days and we will keep you updated until it is fixed.

> **For the app owner:** replace this paragraph with your actual security contact email before publishing.

## Supported versions

Only the latest release receives security fixes.

## Scope notes

QuoteForge Pro is designed for a trusted, private setup. See the **Security** section of the README for what the self-hosted version does and does not protect against (optional password, HTTP Basic auth, plain-text storage of settings and printer credentials).
