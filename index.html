⚙️Configuration

ℹ️How it works

Model files and photos both upload into a Drive folder named "<Job ID>_<Project Name>" — model files link in the "Model Files" column, photos link in the "Images" column, and a single link to the whole folder is kept in "Job Folder" for one-click access to everything. Anyone with the link can view and download either, without needing individual access granted.

Need this set up? See the "Google Sheets Sync Setup" section in README.md — it walks through pasting the included Apps Script into your Sheet and deploying it as a Web App.

Data & Backup

Save or restore everything — settings, jobs, and attached model files — in a single file.

Export Backup

Downloads a dated .json file with your full settings, job history, and attached STL/3MF files.

Importing merges into what's already here — existing settings aren't wiped by an older or partial backup, and jobs already present (matched by timestamp) are skipped rather than duplicated.

Recovering jobs saved before an update?

Local jobs are saved per browser tab and per port — if the app opens on a different address than it used to, older saved jobs won't show up automatically. To recover them: open the old copy of the app in your browser, press F12 to open Developer Tools, click the "Console" tab, paste the snippet below, and press Enter — it downloads a backup file. Then come back here and use "Import Backup" above and choose that file. 

const blob = new Blob([localStorage.getItem("portable3dQuoteConfig")], {type: "application/json"});
const a = document.createElement("a");
a.href = URL.createObjectURL(blob);
a.download = "quote-calculator-backup.json";
a.click();

Discover Printers on Your Network

Scans your network for Bambu Lab, Prusa (PrusaLink), Elegoo (newer SDCP models), Duet / RepRapFirmware, OctoPrint, and anything running Klipper/Moonraker (Voron, Creality K1, Snapmaker U1, QIDI and many more). Bambu printers must have LAN Only Mode on to be usable. Printers on a different network (for example a separate printer Wi-Fi) can be scanned by typing that network in the box. Stock Anycubic and stock Creality/Ender firmware don't offer a local connection.

Connect a Bambu Lab Printer (LAN-only mode)

Scan Network above finds Bambu printers automatically; this form is for entering one by hand. Bambu printers use an access-code-protected local connection — enable LAN Only Mode and Developer Mode on the printer first (Settings → WLAN on the printer's screen), then enter the details shown there.

All three are shown on the printer's own screen under Settings → WLAN once LAN Only Mode is on. Once saved, use the 🔌 icon on the Printers list (or "Check Live Status" on the printer's Edit page) to see its current state, progress, and temperatures. This doesn't start/stop prints — status only.
